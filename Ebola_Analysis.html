Ebola Outbreak Analysis in Sierra Leone

Data Analysis Portfolio Project

2026-10-17

1. Introduction

Ebola virus disease (EVD) is a severe infectious disease. The 2014–2016 West African Ebola epidemic had a major impact on Sierra Leone and highlighted the importance of disease surveillance, reliable data collection, and effective public health responses.

This project uses R to explore reported Ebola records from Sierra Leone. The analysis focuses on case status, age, sex, and district. It applies data quality checks, descriptive summaries, frequency tables, and visualizations to describe patterns in the available records.

The objective is to demonstrate how data analysis can support the exploration and communication of public health information. The findings are descriptive and should not be interpreted as estimates of infection risk.

2. Dataset Overview

The analysis expects the file data/ebola_sierra_leone.csv and uses the following fields:

3.1 Missing values

The following summary checks missing values in the key analysis fields.

missing_summary <- ebola_sierra_leone_clean |>
  summarise(
    missing_status = sum(is.na(status) | status == ""),
    missing_age = sum(is.na(age)),
    missing_sex = sum(is.na(sex) | sex == ""),
    missing_district = sum(is.na(district) | district == "")

5. Confirmed Cases by Sex

Filter to confirmed records with sex values coded as f or m, then compare counts.

confirmed_by_sex <- ebola_sierra_leone_clean |>
  filter(status == "confirmed", sex %in% c("f", "m")) |>
  count(sex, name = "confirmed_cases") |>
  mutate(
    sex = recode(sex, f = "Female", m = "Male")
  )

knitr::kable(confirmed_by_sex,
             caption = "Confirmed records by recorded sex")
Confirmed records by recorded sex
sex confirmed_cases

Male 80 
ggplot(confirmed_by_sex,
       aes(x = sex, y = confirmed_cases, fill = sex)) +
  geom_col(show.legend = FALSE) +
  geom_text(aes(label = confirmed_cases), vjust = -0.4) +
  labs(
    title = "Confirmed Ebola Records by Sex",
    x = "Recorded sex",
    y = "Number of confirmed records"
  ) +
  theme_minimal()

These are counts within the dataset, not sex-specific infection rates. Population denominators and further epidemiological context would be required to compare risk.

6. Age Group Analysis

Age is grouped as follows:

  • Child: under 18
  • Young Adult: 18–29
  • Adult: 30 or older
  • Unknown: age is missing
age_group_summary <- ebola_sierra_leone_clean |>
  mutate(
    age_group = case_when(
      is.na(age) ~ "Unknown",
      age < 18 ~ "Child",
      age < 30 ~ "Young Adult",
      age >= 30 ~ "Adult"
    ),
    age_group = factor(
      age_group,
      levels = c("Child", "Young Adult", "Adult", "Unknown")
    )
  ) |>
  count(age_group, name = "number_of_records")

9. Conclusion

This project demonstrates an exploratory data analysis workflow in R using reported Ebola records from Sierra Leone. The analysis assesses data quality and explores case classifications, demographic patterns by age and sex, and the geographical distribution of records across districts.

The tables and visualizations provide a descriptive view of the records available in the dataset. They can help identify patterns for further investigation, but they do not establish causes or measure population-level infection risk.

A more complete epidemiological analysis would require additional information, such as population denominators, reporting dates, testing and case definitions, and measures of data completeness. Overall, the project highlights the role of data preparation, descriptive analysis, and visualization in communicating public health data.
